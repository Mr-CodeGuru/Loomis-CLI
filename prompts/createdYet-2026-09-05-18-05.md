## 1. Executive Summary

LoomisCLI has successfully expanded from a plain terminal REPL into a dual-mode local-first Retrieval-Augmented Generation (RAG) assistant featuring a high-fidelity, Claude Code-inspired Terminal User Interface (TUI). Powered by Ratatui, Crossterm, Syntect, and Pulldown-Cmark, the new TUI provides real-time token-by-token streaming, full Markdown AST rendering, true language grammar syntax highlighting in framed code blocks, prompt history navigation, and animated status monitoring.

Crucially, this work was delivered with **zero regressions** to the existing plain REPL: all shared RAG logic, semantic intent classification, LanceDB retrieval, and sidecar IPC have been unified into a clean engine layer (`LoomisCore`), and the TUI is gated behind an opt-in `--tui` CLI flag.

## 3. Major Accomplishments & Capabilities Delivered (`v1.2.61`)

### 3.1 Shared Core Extraction (`LoomisCore` in `src/core.rs`)
- Extracted monolithic session logic from `src/cli/session.rs` into an engine struct `LoomisCore` containing:
  - `VectorStore`: LanceDB native connection and vector similarity query executor.
  - `SidecarClient`: Python subprocess IPC for computing Jina embeddings (`768`-dim).
  - `LlmClient`: OpenAI-compatible HTTP/SSE client for intent classification and chat streaming.
  - `AppConfig`: Endpoint URL, model name, API key, and `top_k`.
  - `history: Vec<ChatMessage>`: Ephemeral in-memory multi-turn conversation buffer.
- Introduced `prepare_query(&mut self, query: &str) -> Result<QueryPreparation>`:
  - Pure LLM semantic intent evaluation (`CODE` vs `CHAT`).
  - Retrieval bypass for general chat queries (0 LanceDB queries, 0 sidecar calls).
  - High-relevance vector retrieval for code intent queries.
  - Prompt assembly with system instructions, retrieved code blocks, and conversation history.
- Refactored `ReplSession` to wrap `LoomisCore`, ensuring 100% behavioral parity for the default REPL.

### 3.2 Markdown AST & Syntax Highlighting Engine (`src/tui/markdown.rs`)
- Replaces naive regex matching with a full `pulldown-cmark` event stream parser emitting native Ratatui `Line` and `Span` widgets.
- **Header Formatting**:
  - `H1 (#)`: Bold Cyan with `█ ` block indicator.
  - `H2 (##)`: Bold Light Yellow with `▓ ` indicator.
  - `H3 (###)`: Bold Light Magenta with `▌ ` indicator.
- **Inline Styling**:
  - `**bold**`: Bold modifier with highlighted color.
  - `*italic*`: Italic modifier with dimmed accent.
  - `` `inline code` ``: Rounded pill style with distinct dark background (`Color::Rgb(40, 44, 52)`).
- **Structure & Spacing**:
  - Unordered lists (`• `) and ordered lists (`1. `, `2. `) with hierarchical indentation.
  - Blockquotes: Italics with vertical quote bar prefix (`▎ `).
  - Horizontal rules: Clean border dividers (`────...`).
- **Code Block Framing with Syntect**:
  - Top header border: `╭─── [language] ──────────────────────────────────────────`
  - Body line prefix: `│ ` with syntax highlighting using `syntect` token parsing.
  - Bottom border: `╰───────────────────────────────────────────────────────────`
  - Globally cached `SyntaxSet` and `ThemeSet` (`base16-ocean.dark` Monokai) using `OnceLock` to guarantee zero per-frame allocation overhead.

### 3.3 Interactive TUI Application State Machine (`src/tui/app.rs`)
- **Terminal Lifecycle Management**:
  - Safe alternate screen (`EnterAlternateScreen`) and raw mode activation.
  - Panic hook registration: restores standard terminal mode and disables raw mode even on abnormal panic exit.
  - Clean exit handling on `/exit`, `/quit`, `Ctrl+C`, and `Esc` (when input is empty).
- **Asynchronous Token Streaming Loop**:
  - Live token pieces stream over an unbounded Tokio `mpsc` channel (`RagEvent::Intent`, `RagEvent::Chunks`, `RagEvent::Token`, `RagEvent::Done`).
  - 50ms tick rate (20 FPS) rendering loop preventing UI stutter and flicker.
  - Background task isolation: terminal inputs and scrolling remain completely responsive while the model generates output.
- **Prompt Input & History Recall (`tui-textarea`)**:
  - Multi-line query editing with <kbd>Shift</kbd> + <kbd>Enter</kbd>.
  - Submission with <kbd>Enter</kbd>.
  - Command line prompt history navigation using <kbd>↑</kbd> and <kbd>↓</kbd> arrow keys.
- **Dynamic Viewport Scrolling**:
  - PageUp / PageDown keys allow reviewing earlier conversation turns.
  - Auto-scrolls to latest tokens while generation is active.
- **Real-Time Status Bar & Sources Box**:
  - Displays active model (`Llama-3.2-1B-Instruct-Q8_0`), endpoint (`http://localhost:8080/v1/chat/completions`), state, turn counter, and animated braille spinner (`⠋ ⠙ ⠹ ⠸ ⠼ ⠴ ⠦ ⠧ ⠇ ⠏`).
  - Visual source citations box (`┌ Sources (X snippets) ───...`) showing matched file paths, extracted symbol names, and vector distance metrics per turn.
